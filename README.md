**Project title**
Government Scheme Fund Utilization Tracker

**Objective**
To analyze district-wise government scheme expenditure using HDFS, Hive, Spark SQL, PySpark and R, and identify underutilized allocations.

**Technologies**
1. HDFS
2. Hive
3. Spark SQL
4. PySpark
5. Python
6. R
7. Linux

**Workflow**
Raw Dataset
->
Data Cleaning
->
    HDFS
->
    Hive
->
Spark SQL / PySpark
->
  Analysis
->
R Visualization
->
Performance Reports

**Key analysis**
1. Total expenditure
2. Year-wise expenditure
3. District-wise expenditure
4. District ranking
5. Top 5 districts
6. Highest/lowest expenditure
7. Expenditure growth
8. Underutilized districts
9. Yearly trends
10. R visualizations
